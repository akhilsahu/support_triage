Backlinks = other sites linking to yours; each is a "vote" that builds domain authority. For an **AI chatbot SaaS specifically**, here's what actually works, ranked by ROI:

## 1. Your widget IS a backlink engine (biggest lever, unique to you)
You embed `widget.js` on every customer's website. Add a small **"⚡ Powered by SUPPORT247.chat"** link in the widget (especially on free/starter tiers) → **every customer site becomes a backlink**, with anchor text you control, on topically-relevant pages. This is exactly how Intercom, Tidio, Crisp, and Calendly bootstrapped their authority.
- Make it a real `<a href="https://support247.chat" rel="...">` (dofollow on free tier).
- Optional paid-tier perk: "remove branding."
- **This is a code change I can make** — want me to add it to `widget.js`?

## 2. Listings & directories (fast, high-authority, relevant)
These rank well *and* send buyers. Submit to:
- **Software review sites:** G2, Capterra, GetApp, TrustRadius, SaaSworthy
- **AI tool directories** (huge traffic right now): There's An AI For That, Futurepedia, Toolify, AI Scout, Insidr
- **Launch platforms:** Product Hunt (a strong launch = many natural links), BetaList, AlternativeTo (list yourself as an "alternative to Intercom/Zendesk")
- **App marketplaces:** Shopify App Store, WordPress plugin directory — you already support those integrations, so these are doubly valuable (authority + qualified users)

## 3. Comparison & "alternative" content (earns links + converts)
Create pages like *"Best AI customer support chatbots 2026"*, *"SUPPORT247 vs Intercom"*, *"Zendesk alternatives"*. People searching these are ready to buy, and other blogs cite comparison pages. Pair with the on-page content rewrite I mentioned.

## 4. Founder-led distribution (free, compounds)
- Answer chatbot/support questions on **Reddit** (r/SaaS, r/CustomerSuccess), **IndieHackers**, **Stack Overflow**, **Quora** — link only where genuinely helpful.
- Post build-in-public threads on **LinkedIn/X**.
- **HARO / Connectively / Featured.com** — respond to journalist queries about AI/customer support → earn links from real publications.

## 5. Integrations & partnerships
Each integration partner often lists you in *their* directory with a link (Shopify, WordPress, Zapier if you add it). Co-marketing posts swap links.

## Avoid (gets you penalized)
- Buying links / link farms / PBNs
- Mass low-quality directory spam
- Comment/forum spam with links

## Measure
Track in **Google Search Console** (Links report) + a free **Ahrefs Webmaster Tools** account (backlink profile, referring domains).
